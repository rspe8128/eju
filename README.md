# EJU Study

일본유학시험(EJU) 준비용 개인 학습 웹앱입니다.
학습 진행도는 브라우저 localStorage에 자동 저장됩니다.

## 라이브

https://eju-nu.vercel.app

## 실행

```bash
npm install
cp .env.example .env.local   # DeepL 키 입력
npm run dev
```

## 환경 변수

| 이름 | 용도 |
|---|---|
| `DEEPL_API_KEY` | 기출 지문 한국어 번역. 무료 플랜 키는 `:fx`로 끝나며 월 50만 자까지 무료. |

`.env.local`은 git에 올라가지 않는다. Vercel 배포 시 Project → Settings → Environment
Variables에 같은 이름으로 등록해야 번역이 동작한다.

## 기출 풀이 (`/exam`)

JASSO 공식 기출을 실전 시간표로 풀고 채점 결과를 약점 분석으로 넘긴다.

문제 원문은 **이 저장소에 담지 않는다.** 두 가지 이유가 있다.

1. **저작권** — JASSO 고지상 기출의 웹 업로드·공중송신·번안(번역 포함)은 금지되어 있고,
   "개인적 이용 목적의 열람·인쇄"만 허용된다. 그래서 원본 PDF를 열어서 읽는 방식으로 만들었다.
2. **애초에 원문이 없다** — 일본어 과목 공개본은 독해 지문이 통째로 삭제돼 있다.
   PDF에 남은 문구가 「試験問題としては成立していますが、著作権上の都合により本問題の
   ウェブ掲載はいたしません。」로, 지문 원저자가 웹 게재를 허락하지 않았다.
   수학·이과 PDF는 텍스트 레이어 없는 스캔본이라 기계 추출 자체가 불가능하다.

대신 이렇게 동작한다.

- 회차·과목 선택 → 공식 PDF를 화면에 띄우고 실전 타이머 시작 (일본어 125분 3단계 등)
- 오른쪽 마크시트에 답 입력 → 제출 시 자동 채점
- 정답표는 회차·과목당 한 번만 등록하면 이후 자동 채점 (`3142…` / `3,1,4,2` / `1:3 2:1` 형식 지원)
- 오답에 단원 태그를 붙이면 `/stats` 약점 분석에 단원별 정답률로 집계된다
- 번역 패널에 지문을 붙여넣으면 DeepL이 한국어로 번역 (저장하지 않음)

JASSO 공개 범위는 2010년 1차 ~ 2021년 1차다. 2018년 2차 이후 회차는 일본어·종합과목이
아직 미공개라 목록에서 자동으로 빠진다.
